Política de Privacidade

Em conformidade com a Lei Geral de Proteção de Dados (Lei 13.709/2018).

1. Quais dados coletamos

Coletamos os dados que você fornece ao se cadastrar e ao montar seu perfil familiar: nome, CPF, e-mail, data de nascimento, senha, membros da família, idade, parentesco, vínculo de trabalho e renda mensal.

2. Como armazenamos

Nesta versão do aplicativo, todos os seus dados ficam armazenados no armazenamento local do navegador que você usa (localStorage). Eles não trafegam pela internet para servidores nossos e não são compartilhados com terceiros.

3. Para que usamos

Os dados são usados exclusivamente para:

  • Calcular sua renda per capita
  • Avaliar a quais benefícios você provavelmente tem direito
  • Permitir que você marque documentos como obtidos
  • Gerar resumos para imprimir, compartilhar via WhatsApp ou baixar em PDF, sob sua iniciativa

4. Compartilhamento

Não compartilhamos seus dados com terceiros. Quando você clica em "Compartilhar no WhatsApp", o texto vai apenas para o aplicativo do WhatsApp no seu dispositivo, e é você quem escolhe o destinatário.

5. Serviços externos

Para localização de unidades, consultamos o serviço público ViaCEP enviando apenas o CEP digitado. Nenhum outro dado seu é enviado nessa consulta.

6. Seus direitos

Você pode, a qualquer momento:

  • Acessar e editar seus dados em "Meu Perfil"
  • Excluir sua conta e todos os dados associados pelo botão "Excluir conta"
  • Limpar manualmente os dados pelo navegador

7. Contato

Para dúvidas sobre privacidade, abra uma issue no repositório do projeto. Como este aplicativo é parte de um trabalho acadêmico, não há um canal oficial de DPO.
